# Tmux 配置

[Tmux](https://github.com/tmux/tmux) 是一个终端复用器。

## 前缀键

前缀键改为 `Ctrl+A`（默认为 `Ctrl+B`）。

## 快捷键

### 面板分割

| 快捷键 | 操作 |
|--------|------|
| `prefix + v` | 垂直分割面板 |
| `prefix + s` | 水平分割面板 |
| `prefix + ^v` | 垂直分割面板（重复） |
| `prefix + ^s` | 水平分割面板（重复） |

### 面板切换

| 快捷键 | 操作 |
|--------|------|
| `prefix + k` | 焦点上移 |
| `prefix + j` | 焦点下移 |
| `prefix + h` | 焦点左移 |
| `prefix + l` | 焦点右移 |
| `prefix + K` | 焦点上移（重复） |
| `prefix + J` | 焦点下移（重复） |
| `prefix + H` | 焦点左移（重复） |
| `prefix + L` | 焦点右移（重复） |

### 面板调整大小

| 快捷键 | 操作 |
|--------|------|
| `prefix + ^k` | 上移边缘 10 单元 |
| `prefix + ^j` | 下移边缘 10 单元 |
| `prefix + ^h` | 左移边缘 10 单元 |
| `prefix + ^l` | 右移边缘 10 单元 |

### 面板操作

| 快捷键 | 操作 |
|--------|------|
| `prefix + e` | 选择最后一个面板 |
| `prefix + ^e` | 选择最后一个窗口 |
| `prefix + ^u` | 与前一个面板交换位置 |
| `prefix + ^d` | 与后一个面板交换位置 |

## 其他设置

- 默认 shell：`zsh`
- 启用鼠标支持
- 启用 vi 模式
